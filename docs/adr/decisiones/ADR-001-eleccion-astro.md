# ADR-001 – Elección de Astro como framework

## Contexto
El proyecto necesita un sitio web para mostrar el portfolio y la biografía de una banda musical, junto con una API para acceder a los datos.

## Decisión
Utilizar Astro como framework para desarrollar el sitio web y sus endpoints de backend dentro de un mismo proyecto.

## Consecuencias

### Positivas
- Permite desarrollar el frontend y los endpoints de la API dentro de una misma aplicación.
- Reduce la necesidad de mantener proyectos separados para el frontend y el backend.
- Facilita la organización y el desarrollo del proyecto en un único repositorio.

### Negativas
- El equipo debe conocer cómo Astro gestiona tanto las páginas como los endpoints del servidor.
- La aplicación depende de las capacidades y convenciones del framework elegido.

## Estado
Aceptado.
