# ADR-002 – Uso de PostgreSQL como base de datos

## Contexto
El portfolio necesita almacenar álbumes, canciones, conciertos y biografía, con datos relacionados entre sí.

## Decisión
Utilizar PostgreSQL como sistema de gestión de base de datos relacional.

## Consecuencias

### Positivas
- Ofrece integridad referencial, relaciones entre entidades y transacciones.
### Negativas
- Es necesario instalar y configurar el servidor de base de datos y administrar el esquema.

## Estado
Aceptado.
